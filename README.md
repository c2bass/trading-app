# Trading Journal (Web)

A simple web-based trading journal with Supabase backend.

## Features

✅ **Track trades** - Log entry/exit prices, quantity, fees, emotions
✅ **P&L calculations** - Automatic profit/loss calculation
✅ **Cloud sync** - All data stored in Supabase
✅ **Authentication** - Secure login with Supabase Auth
✅ **Dashboard** - Quick overview of trading stats

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Deploy to Vercel:
   - Push to GitHub: `git push origin main`
   - Import repo in Vercel dashboard
   - Add environment variables (VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY)
   - Deploy!

## Local Development

```bash
npm run dev
```

Visit http://localhost:5173
